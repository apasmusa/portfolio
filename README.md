# Портфолио Дмитрия Сандиева

Статические страницы портфолио. GitHub Pages публикует сайт из корня ветки `main`.

- `index.html` — главная страница.
- `case-*.html` — кейсы.
- `styles.css` и изображения — оформление и иллюстрации.

При обновлении сайта изменяйте файлы в этом репозитории и отправляйте изменения в `main`.
