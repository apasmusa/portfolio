Кейс 04 / ГК СКС

Собрал документы отдела в локальную базу знаний

В проектном отделе нужны уставы, протоколы, регламенты, инструкции и шаблоны. Я организовал для них общий репозиторий с понятными папками: коллеги хранят копию на своём компьютере, читают документы в Obsidian и автоматически получают новые материалы. Для новых участников написал пошаговую инструкцию.

Задача

Дать коллегам общий доступ к документам

Нужно было хранить рабочие материалы отдела в понятной структуре и дать каждому участнику локальную копию. При этом важно видеть изменения в файлах и быстро находить нужный документ.

Организация

Разложил документы по типам

В репозитории выделил пять разделов: проекты, протоколы, нормативные документы, инструкции и шаблоны. В инструкции описал, как получить приглашение, скачать папку на компьютер и открыть её в Obsidian. Там же показал, как связывать документы ссылками, чтобы переходить из протокола к уставу проекта.

02 / КопияДокументы на компьютере

Для тех, кто только читает материалы, и тех, кто добавляет документы, описал разные настройки синхронизации. Так у читателей изменения не отправляются обратно в общий репозиторий.

Файлы

Связал Word и Markdown

Для добавления Word-документа коллега может запустить Claude Code из папки репозитория: он кладёт исходный файл в нужный раздел и делает версию Markdown для просмотра в Obsidian. Если после редактирования Markdown снова нужен Word, документ переводится через Pandoc.

Исходный Word и версия Markdown остаются отдельными файлами. После правки одного второй нужно конвертировать заново — это явно указано в инструкции.

Синхронизация

Новые документы появлялись у коллег автоматически

Я настроил синхронизацию через Obsidian Git. После добавления документа остальные коллеги сразу видели его в своей базе знаний: локальные копии обновлялись без ручного запуска git pull.

Результат

Понятное место для документов отдела

Проектные материалы, протоколы и шаблоны получили общую структуру и историю изменений. Коллегу можно подключить по инструкции: выдать доступ, скачать копию и открыть её в Obsidian. Дальше новые документы появлялись у него автоматически. Правила конвертации и синхронизации записаны, поэтому их не приходится объяснять каждому заново.
